# VOYGE.studio 🗡️

**Your social media saves, mathematically perfected.**

VOYGE.studio is a high-fidelity travel intelligence platform designed to turn fragmented social media "saves" into actionable, optimized itineraries. Built with a Vercel-inspired aesthetic, it bridges the gap between digital inspiration and physical exploration.

![VOYGE Dashboard Preview](./public/preview.jpg)

## 🗡️ The Why

We all have them: hundreds of bookmarked Reels and TikToks of "hidden gems," aesthetic cafes, and breathtaking viewpoints. But when it actually comes time to travel, those saves remain buried in an endless scroll. 

**VOYGE.studio** solves this by acting as the bridge between digital inspiration and physical exploration. It doesn't just store your spots; it understands them. By combining the precision of **GPT-4o** with the mathematical efficiency of the **Mapbox Optimization Engine**, VOYGE transforms your social media clutter into a logical, day-by-day path.

## 🚀 Core Features

### 1. The Link Engine
*   **Instagram & TikTok Integration:** Paste any Reel or TikTok link to extract location data instantly.
*   **AI-Powered Extraction:** Uses **GPT-4o** to parse captions and identify specific businesses, landmarks, and vibes.
*   **Verified Pro-Scraping:** Powered by high-reliability APIs to bypass social media security walls.

### 2. Intelligent Mapping
*   **Master Map:** A unified dark-mode globe view of every spot you've ever saved.
*   **Country Folders:** Automatic classification of spots into dynamic country-based folders.
*   **Native Interactivity:** Smooth "Fly-To" animations when clicking spots on iPad, iPhone, or Desktop.

### 3. Route Optimization
*   **Mathematical Perfected Itineraries:** Powered by the **Mapbox Optimization Engine**.
*   **Folder-Aware Planning:** Plan day-trips specific to a country or region to eliminate travel "zig-zagging."
*   **Visual Routing:** Robust, glowing pathing system for clear navigation.

### 4. Ecosystem Integrations
*   **Telegram Bot (@Voygevercelbot):** Forward Reels directly to your bot to "teleport" them to your map without opening the app.
*   **iOS Shortcut:** Direct integration into the Apple Share Sheet for one-tap syncing.

## 🛠️ Tech Stack

*   **Frontend:** Next.js 15 (App Router) + Tailwind CSS + Framer Motion.
*   **Backend:** Vercel Serverless Functions (API).
*   **Database & Auth:** Firebase Firestore & Firebase Auth.
*   **Intelligence:** GitHub Models (GPT-4o) + RapidAPI Pro Scrapers.
*   **Geo-Spatial:** Mapbox GL JS v3 + Search JS + Optimization API.
